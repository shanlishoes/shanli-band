# کارکردینو — ثبت کارکرد روزانه

اپلیکیشن موبایل‌پسند برای ثبت کارکرد ۳ نفر و ذخیره در Google Sheets؛ هر نفر در هر روز فقط یک ثبت دارد.

## راه‌اندازی محلی
```bash
npm install
cp .env.example .env.local
npm run dev
```

## ساخت Google Sheet
ساختار فایل شما از روی تصویر تنظیم شد: تب `DATA` و ستون‌ها به این شکل هستند:

`تاریخ | برج | سمیه فلاح پور | ثنا آخته | گیتا ازم | جمع ردیف`

برنامه ردیف تاریخ امروز را پیدا می‌کند، مقدار را در ستون پرسنل می‌نویسد و ستون «جمع ردیف» را با فرمول جمع ستون‌های C تا E به‌روزرسانی می‌کند. بنابراین لازم است ردیف‌های تاریخ روزهای ماه از قبل در جدول وجود داشته باشند.

در Google Cloud یک پروژه بسازید، Google Sheets API را فعال کنید، یک Service Account بسازید و کلید JSON بگیرید. ایمیل Service Account را به‌عنوان Editor روی فایل Sheet share کنید. کل محتوای JSON را در `GOOGLE_SERVICE_ACCOUNT_JSON` به‌صورت یک خط در Environment Variables قرار دهید.

## انتشار روی Vercel
1. این پوشه را به GitHub push کنید.
2. در Vercel گزینه Add New Project و سپس repository را انتخاب کنید.
3. در Settings → Environment Variables این موارد را اضافه کنید: `GOOGLE_SERVICE_ACCOUNT_JSON`، `GOOGLE_SHEET_ID`، `GOOGLE_SHEET_TAB=کارکرد` و `APP_TIMEZONE=Asia/Tehran`.
4. Deploy بزنید. لینک ایجادشده را برای پرسنل بفرستید.

## تغییر نام‌ها
نام‌های پرسنل در `app/page.tsx` و `app/api/attendance/route.ts` تنظیم شده‌اند: سمیه فلاح پور، ثنا آخته و گیتا ازم.

## پیشنهادهای قابل اضافه‌کردن
- PIN اختصاصی برای هر فروشنده
- پنل مدیر با فیلتر ماه و خروجی Excel
- ثبت مرخصی/مأموریت و ضمیمه تصویر
- قفل خودکار پایان ماه و گزارش جمع ساعات

نکته: قانون «فقط امروز» و «یک‌بار در روز» در سمت سرور بررسی می‌شود؛ ذخیره‌سازی مرورگر فقط برای بهبود ظاهر و جلوگیری از کلیک تکراری است.
